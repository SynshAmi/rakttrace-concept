The request, as it was forwarded

Stock first

Old listings are treated as unconfirmed. The agent asks every nearby blood centre to confirm, and only messages donors if stock can’t cover the need.

One number decides

The agent keeps a live chance that all units are ready by the deadline, counting testing time. Below 90% it messages a few more donors. Below 30% it hands over to a person.

Done means confirmed

A request closes only when a blood centre confirms the units. Then everyone is stood down and the family gets a “please stop forwarding” message.

One run is a story. Many runs are evidence.

Run it on many random requests

Both approaches get the same blood centres, donors and replies. Only the decisions differ.

Half the requests are whole blood with short deadlines (where stock matters), half are single-donor platelets (where donors matter). Assumed: a donated unit needs 12 hours of testing for whole blood and 6 hours for platelets; 30% of yes replies are for a later time; 12–25% of willing donors are deferred at screening. These are behaviour checks on synthetic data, not real-world results.
